# Pixel Map Tracker

Tiny Minecraft pixel-map click-to-coordinates tracker for `pixelmap.chaoscat.win`.

## Use

1. Load or drag in a map image.
2. Enter the world coordinate bounds for the image edges.
3. Click the player location on the map.
4. Copy the estimated `X, Z` coordinates.

Everything is local browser state. No backend, no accounts, no map uploads.

## Dev

```bash
bun install
bun run dev
bun run build
```
